# Swap Doctor v1.0.0

这是 Swap Doctor 的首个公开版本，面向 Minecraft 1.21.11 的 Fabric 客户端。

## 主要内容

- 快捷栏切换、主/副手交换与左右键输入的本地 timing 匹配。
- 同 tick 通过、跨 tick 失败和有符号毫秒间隔显示。
- 数据 HUD 与无背景刻度 HUD。
- 显示模式、淡出时长、刻度宽度、长度/厚度倍率、正方向、小数毫秒和布局编辑器。
- 严格 JSON 配置、中文/英文翻译和自动化测试。

## 依赖与安装

- Minecraft 1.21.11
- Fabric Loader 0.20.1+
- Fabric API（本版本使用 `0.141.6+1.21.11` 测试）
- YACL（本版本使用 `3.8.2+1.21.11-fabric` 测试，运行时最低版本为 `3.8.2`）
- Java 25 用于运行当前构建链；源码以 Java 21 目标编译
- Mod Menu 可选

将 `swap-doctor-1.0.0.jar` 放入客户端实例的 `mods` 文件夹。该 Mod 是 client-only，不需要安装到服务器。

## 限制

本版本只报告客户端本地时序，不确认伤害、附魔、图腾消耗、数据包顺序或服务器端属性效果。真实游戏交互仍需按 [`docs/manual-smoke-test.md`](../manual-smoke-test.md) 手动验收。
